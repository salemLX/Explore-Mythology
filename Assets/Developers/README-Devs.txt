1. Ownership & File Headers

Never put developer names in folder, class, method, or interface names

      (use `IDamageable`, not `ISalemDamageable`).

Add a header comment at the top of every script you create so the team knows who owns it:

  // Author: [Your Name]
  // Created: [DD-MM-YYYY]
  // Description: [Short summary of what this script does]

Editing an existing script: If you modify or add code to a script created by someone else, add your name and a short note to the header without removing the original author:

   "Modified by" alleen bij belangrijke wijzigingen, als extra uitleg nodig is.
  // Modified by: [Your Name] ([DD-MM-YYYY]) - [What you changed/added]
